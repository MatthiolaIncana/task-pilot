# Handoff / 交接

## 何时生成

仅在以下场景生成正式交接：

- 长期或复杂项目需要跨会话继续；
- 更换模型、Agent、执行者或环境；
- 当前任务中断，但已有大量已验证成果需要继承；
- 用户明确要求形成交接记录。

简单任务不生成交接材料。

## 最小交接内容

- 当前目标；
- 当前适用的工作流 / Skill / 项目规则；
- `VERIFIED` 内容；
- `IMPLEMENTED_UNVERIFIED` 内容；
- `PENDING` 内容；
- 关键有效决策；
- 当前阻塞或真实限制；
- 下一步应从哪里继续；
- 哪些内容明确不得重做或回退。

## 原则

交接是状态快照，不是新的规则真源。后续继续执行时仍以当前实际文件、源码、日志、测试和输出核实状态。
