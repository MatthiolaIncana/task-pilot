# Unknowns / 关键未知控制

## 只处理会改变结果的未知

把未知分成四类：

1. 可自行查证：通过当前上下文、文件、源码、日志、工具或可靠外部资料能够确认。先查，不问用户。
2. 可保守处理：存在多个细节可能性，但不会改变核心结果。采用最小范围、可逆、保守方案继续。
3. 必须由用户决定：目标、偏好、成本、不可逆取舍，且不同答案会明显改变结果。
4. 暂不影响：当前阶段不需要答案。记录为待定，不阻塞当前工作。

## 何时提问

仅在以下情况暂停：

- 缺失信息会实质改变最终结果或下一步方向；
- 下一步是明显不可逆、破坏性或高影响操作；
- 同优先级规则发生真实冲突，无法可靠裁决；
- 用户必须做真实偏好或成本选择。

提问前先完成不依赖该答案的可靠工作。

## 追问停止条件

剩余未知已经不会明显改变下一步时停止追问。

不要为了“深度”持续挑战已经清楚、已验证或已明确决定的事项。
