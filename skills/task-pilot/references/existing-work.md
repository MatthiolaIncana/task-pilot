# Existing Work / 已有项目与接续

## 基本原则

继续已有工作时，先确认“现在实际上是什么状态”，再决定从哪里继续。

## 优先核实

按任务需要检查：

- 当前源码和已保存修改；
- 运行中、卡死或中断的进程；
- 配置、依赖和环境；
- 最新日志、测试、构建和真实输出；
- 已验证能力与仅实现未验证内容；
- 未完成、废弃、临时或重复产物；
- 直接受当前修改影响的历史兼容要求。

## 继承原则

- 已验证且未要求修改：保留，不重做。
- 已实现未验证：优先补验证，不直接宣称完成。
- 未完成：从真实未完成位置继续。
- 已废弃：不因为旧记录重新启用。
- 出现新证据：只重新评估直接受影响的决定和范围。

## 证据优先级

当前实际文件、源码、日志、测试、构建与输出 > 旧任务列表、旧对话摘要、口头状态描述。

旧记录用于定位和解释，不用于覆盖当前可验证事实。
