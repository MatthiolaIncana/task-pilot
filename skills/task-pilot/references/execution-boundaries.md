# Execution Boundaries / 执行边界

## 默认行为

- 保留已经正确、有效且未被要求改变的内容。
- 只修改真正受当前任务影响的部分。
- 发现关联问题时检查直接受影响范围，不无依据扩大到整个系统。
- 不为了“优化”“统一”“现代化”进行无目的重构。
- 不因为存在更先进方案就替换当前仍满足目标的稳定方案。
- 不重复实现已经验证通过的能力。

## 自动操作边界

只读、分析、搜索、检查、测试和可逆修改，在任务已授权范围内可直接进行。

明显不可逆、破坏性或会改变核心目标/范围的操作，需要用户做真实选择时再暂停。

## 范围变化

执行中如果发现原假设不成立：

1. 判断是否只影响局部实现；能局部修正就直接修正。
2. 如果会改变用户目标、核心范围或已确认重大决策，停止扩大执行并提交具体差异给用户决定。

## 专业规则

Task Pilot 不修改专业 Skill 的业务规则。专业问题回到对应专业流程处理。
